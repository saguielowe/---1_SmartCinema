# 用户操作流程

我们把自动发生的环节单独标出来，不算进用户需要做的三步。首次使用时用户注册并登录；之后可以直接保持登录状态。推荐由系统自动完成，用户不需要再点一层页面等结果。

```mermaid
flowchart LR
    A[自动登录：首次使用时注册/登录] --> B[1. 输入场次和购票内容]
    B --> C[系统自动推荐]
    C --> D[2. 确认推荐或手动改座并付款]
    D --> E[3. 查看订单和取票号]
```

## 每一步放什么

| 步骤 | 页面内容 | 用户操作 |
| --- | --- | --- |
| 1. 输入 | 电影/场次、票种、人数、成员姓名和年龄 | 填完后直接出现推荐 |
| 2. 确认 | 推荐理由、Canvas 座位图、总价、模拟支付 | 接受推荐；不满意就点座位修改，再确认付款 |
| 3. 查看 | 订单状态、座位号、取票号 | 查看结果；后续可取消预订或退票 |

无障碍模式做成全局开关；管理员后台从导航进入，不塞进普通用户的购票主线。

实现时我们可以用同一页分区或步骤条完成三步，不必为了凑流程额外跳页。这样更符合题目“别让用户思考”的要求。
