# 功能清单

以下功能均已接入正式页面；提交前仍需全组在最终合并版本交叉验收。

## 必须完成

- 登录注册：普通用户注册后登录；管理员登录后能进入管理视图。
- 三个影厅：严格提供 100、200、300 座的小厅、中厅和大厅；均为 10 排，每排分别为 10、20、30 座。用走道、横向偏移和弧度绘制弧形布局，并显示排号和座位号。
- Canvas 选座：空座绿色、已选黄色、已售红色；支持单选、`Ctrl + 点击` 多选，且能在推荐后改选。
- 智能推荐：选择观影类型和人数，并按需勾选儿童、老人及无障碍需求；支持个人、情侣、家庭、团体。少年避开前三排，老人优先避开最后三排；团体票优先推荐同排连续座位，最长连座不足时可拆为相邻座位区。
- 热度图：仍用 Canvas，按红/黄/绿标出热门/一般/冷门，并能切换查看一周内不同日期的数据；色盲模式改用蓝/黄/紫和图形标记。
- 体验评分：根据视角、距银幕和周边空位给出“极佳/优秀/一般”；已支付订单所属观众可提交 1–5 分和短评，订单卡展示系统、观众及综合结果；管理员满意度只统计有效观众评分，不混入系统分。
- 无障碍：大字体、高对比度、色盲友好配色；语音提示可作为可选项。
- 订单：预订后锁座 15 分钟，可稍后支付、主动取消、模拟支付购票或退票；数据保存在 LocalStorage。

## 演示时的主线

1. 输入电影/场次和购票内容，系统自动给出推荐。
2. 确认推荐或手动调整座位，然后完成模拟支付。
3. 查看订单和取票号，并提交观众评分；管理员可查看各场次纯观众满意度。

## 额外加分（已完成）

1. 问答式推荐：支持自然语言人数、成员和偏好识别，自动给座位，并解释视角、噪音和便捷性。
2. 拖拽与动画：Ctrl/Cmd 连续区间拖选不受指针采样速度影响，并提供选择/取消动效。
3. 个性化影厅与界面：三个自定义弧形影厅，并提供午夜青、星河紫、暖金幕主题。
4. WebSocket 实时同步：原生 WebSocket + Python 标准库服务端；不可用时回退到 BroadcastChannel 本机模拟。
