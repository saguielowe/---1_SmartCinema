# 功能清单

这份清单按照“保分优先、体验增强、加分项”排序，开发时先完成主链路。

## 一、必须优先完成

### 1. 登录注册

- 用户注册
- 用户登录
- 普通用户角色
- 管理员角色

### 2. 电影与场次信息

- 电影列表
- 场次列表
- 影厅信息展示
- 价格展示

### 3. Canvas 影厅座位图

- 银幕绘制
- 影厅弧形排布
- 三种影厅规模
- 排号与座位号显示
- 颜色区分：
  - 空座绿色
  - 选中黄色
  - 已售红色

### 4. 智能推荐

- 少年避开前三排
- 老年人避开最后三排
- 情侣推荐连续双座
- 家庭推荐连续座位
- 团体推荐同排连续座位
- 推荐理由展示

### 5. 手动选座

- 单选
- 多选
- 与推荐结果联动
- 切换推荐/手动选择

### 6. 订单中心

- 预订
- 取消预订
- 购票
- 退票
- 订单列表

## 二、第二阶段补强

### 7. 热度地图

- 基于热度数据着色
- 热门 / 一般 / 冷门区分
- 至少演示不同场次或不同日期的变化

### 8. 观影体验评分

- 视角评分
- 距离评分
- 周边空位评分
- 输出：极佳 / 优秀 / 一般

### 9. 无障碍模式

- 大字体模式
- 高对比度模式
- 色盲友好配色
- 可选语音提示

### 10. 响应式页面

- PC 可用
- 平板可用
- 手机可用

## 三、说明文档要求

- 产品设计过程
- 用户分析过程
- AI 使用说明
- 学生修改内容
- 用户体验优化记录
- 设计决策说明
- 参考资料列表

## 四、建议的演示主链路

1. 登录
2. 选择电影和场次
3. 填写用户条件
4. 查看推荐座位
5. 手动调整
6. 下单
7. 查看订单 / 热度 / 评分

## 五、加分项建议

### 优先考虑

- AI 顾问式推荐交互
- 拖拽选座
- 动画交互优化
- 个性化影厅布局

### 谨慎考虑

- WebSocket 实时座位更新

原因：

- 这个点工程量大
- 容易把项目拖成前后端联调
- 对当前作业的性价比不高

## 六、最低可提交版本

如果时间紧，至少保证：

- 登录注册可跑通
- 电影/场次/影厅数据完整
- Canvas 座位图可交互
- 推荐规则能工作
- 订单中心能演示
- 文档能完整说明设计过程
