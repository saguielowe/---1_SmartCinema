# 功能清单

先以能完整演示、能覆盖评分点为目标。拖拽、动画和问答式推荐留到主流程稳定后再做。

## 必须完成

- 登录注册：普通用户注册后登录；管理员登录后能进入管理视图。
- 三个影厅：为了覆盖评分点，准备总座位数分别约为 100、200、300 的三个预设影厅；每个厅仍保持 10 排，但每排座位数可以不同。用走道、空缺、横向偏移和弧度做出不规则布局，座位总数按 `S/W` 实际统计，显示排号和座位号。
- Canvas 选座：空座绿色、已选黄色、已售红色；支持单选、`Ctrl + 点击` 多选，且能在推荐后改选。
- 智能推荐：输入观影类型、人数和成员姓名/年龄；支持个人、情侣、家庭、团体。少年避开前三排，老人避开最后三排，团体 5 到 20 人同排连续。
- 热度图：仍用 Canvas，按红/黄/蓝标出热门/一般/冷门，并能切换查看一周内不同日期或场次的数据。
- 体验评分：根据视角、距银幕和周边空位给出“极佳/优秀/一般”；观影后可提交用户评分，并和系统评分一起展示。
- 无障碍：大字体、高对比度、色盲友好配色；语音提示可作为可选项。
- 订单：预订、取消预订、模拟支付购票、退票；数据保存在 LocalStorage 或本地 JSON。

## 演示时的主线

1. 输入电影/场次和购票内容，系统自动给出推荐。
2. 确认推荐或手动调整座位，然后完成模拟支付。
3. 查看订单和取票号。

## 额外加分，按优先级做

1. 问答式推荐：把已有规则包装成“说需求 - 给座位和理由”的交互，不需要训练或部署大模型。
2. 拖拽选座和少量动画。
3. 个性化影厅布局：用走道、空缺、偏移和弧度展示更真实的排布。
4. WebSocket 实时同步：时间非常充裕再考虑；它不影响基础功能得分。

## 提交材料别漏

- `index.html` 可直接在浏览器打开，或在报告中写清启动方式。
- `report.pdf`：姓名、学号、邮箱、产品与用户分析、设计过程、AI 使用和人工修改、优化过程、设计决策、参考资料。
- 色彩方案、布局、字体和整体设计风格说明。
- 用户操作流程图，用户实际操作不超过三步，见 [用户流程](./user-flow.md)。
