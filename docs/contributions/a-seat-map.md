## 本次完成

- 根据 C 的 `hall.rows[].pattern` 和 `seatState` 绘制三种影厅。
- 排号按每排左端最低座位的曲线高度对齐，避免弧形布局中排号悬在座位上方。
- 修复座位编号：`X`（空白）和 `A`（过道）不计入编号，与 C 的 `generateSeatState()` 一致。
- 桌面普通点击替换当前编辑座位，Ctrl/Cmd + 点击增删多选。
- 支持 Ctrl/Cmd + 拖动批量增删座位；拖动时锁定起始排，只用终点横坐标确定结束座位，再按起止编号补齐完整区间，因此不依赖 Canvas 帧率或 `pointermove` 数量；第一次手动拖动会先替换自动推荐选区；移动端直接点击增删。
- `sold` / `reserved` 座位不可选择。
- 按购票人数限制最多选择数量。
- 场次无默认值；选择场次后立即按人数、票种和偏好推荐并选中座位。
- 个人/情侣/家庭/团体票默认人数分别为 1/2/3/5；个人票人数改为多人时自动切换团体票，情侣票人数不再为 2 时按人数切换票种。
- 观影人群改为儿童、老人复选框；家庭票默认勾选儿童。
- 无障碍模式开启时自动勾选无障碍座位需求并切换为后排优先，关闭后恢复中间优先。
- 无障碍模式开关按账号持久化；重新进入或再次登录同一账号时恢复上次状态。
- 支持方向键移动焦点、Enter/空格选择。
- 显示当前指向座位编号，解决大厅座位密集时编号难以辨认的问题。
- 座位状态与热度提示采用固定高度和懒更新，鼠标离开座位时保留上次内容，避免按钮区域上下跳动。
- 每个影厅在 F/H/J 排靠过道提供六个 `W` 无障碍座位，并使用始终可见的蓝色 `W` 徽标。
- 推荐座位圆本体在绿色与橙色之间呼吸闪烁；人数、票种或偏好变化时自动刷新。
- 已接入 B 的正式推荐与体验评分；清空推荐后，普通点击替换、Ctrl/Cmd + 点击增删多选均由 A 独立维护，不再触发自动补座。
- 团体票先保留 B 的同排连座优先规则；若最长连座不足，则接入多个相邻连续座位区的兜底推荐，并明确提示已拆分。
- 热度由已支付/锁定订单形成热源向邻座扩散，并叠加中间排和中间列位置权重；Canvas 正常模式使用绿色冷门、黄色一般、红色热门，色盲模式改用蓝/黄/紫。
- 支持选择本场放映日前一周的任意日期；订单热源按日期逐步加入，Canvas 动态重绘一周内的热度变化。
- 热度默认隐藏，通过“显示热度”开关按需叠加，避免热度色与座位状态色同时干扰选座。
- 选座数量等于人数时启用“确认座位”按钮，提交标准事件给 D。
- “确认座位”直接调用 C 的 `createOrder()` 锁票并重绘 Canvas；支付对话框可立即调用 `payOrder()`，也可关闭并保留 15 分钟待支付订单，主动取消仍在订单中心处理。
- 个人订单中心在锁票、支付、取消后立即更新；订单持久化到 C 的 LocalStorage，管理员登录后可查看全量订单。
- 订单中心使用卡片展示影片、场次、影厅、座位、金额、状态、下单时间和取票码，并按状态提供支付、取消或退票操作。
- 当前账号头像与用户名移到页面顶部；当前场次库存移到座位图上方，订单中心只保留订单卡片。
- 推荐结果同时写入 `highlightedSeatIds` 和 `selectedSeatIds`，用户可直接确认。
- 修复 B 评分修正引入的推荐转手动选择回归：第一次单击整体替换推荐，第一次 Ctrl/Cmd 拖动整体替换为连续区间，手动选择后隐藏推荐高亮。
- 管理员按场次展示只读座位图、库存、订单、上座率、估算票房和纯观众满意度，并支持全部场次对比。
- 通过自定义事件和公开接口输出 `selectedSeatIds`。

## A → D/C 对接接口

页面可监听：

```js
window.addEventListener("smartcinema:seat-selection-change", (event) => {
  const { scheduleId, selectedSeatIds } = event.detail;
});

window.addEventListener("smartcinema:seat-selection-submit", (event) => {
  const { scheduleId, selectedSeatIds, ticketType, peopleCount } = event.detail;
});
```

也可读取：

```js
window.__seatSelection.getScheduleId();
window.__seatSelection.getSelectedSeatIds();
window.__seatSelection.refreshRecommendation();
```

当前 `app.js` 已按以下方式把选择结果传给 C；D 整合页面时保持参数结构即可：

```js
store.createOrder({
  scheduleId,
  seatIds: selectedSeatIds,
  ticketType,
  peopleCount,
});
```

## 功能验收

1. 打开 `http://localhost:8080/index.html`。
2. 场次列表应显示 12 个场次，可切换大/中/小厅。
3. 小厅/中厅/大厅均显示 A-J 共 10 排，每排分别为 10/20/30 座，总数严格为 100/200/300。
4. 初始场次为空，票种、人数和偏好已有默认值；确认座位按钮禁用。
5. 选择任一场次后应立即出现推荐座位，确认座位按钮直接启用。
6. 修改人数、票种或偏好后推荐应自动刷新；手动改座后也可点击“重新生成推荐座位”恢复推荐。
7. 清空推荐座位后，点击选择第一席，Ctrl/Cmd + 点击或 Ctrl/Cmd + Enter 可继续多选，不应被自动推荐覆盖。
8. 保留自动推荐选区，按住 Ctrl/Cmd 从弧形座位排的第一个座位快速拖到最后一个座位；推荐选区应被替换，起止编号之间的可用座位应连续增选；从已选座位开始再次操作应连续取消。
9. 三个影厅的 F/H/J 排靠过道位置均应显示蓝色方形 `W` 无障碍座位，每厅共六个。
10. 热度默认隐藏；点击“显示热度”后，底色应按绿/黄/红体现冷门/一般/热门，并支持切换一周日期动态重绘。
11. 确认座位后座位应先变为锁定并弹出支付对话框；支付后变已售，选择稍后支付则保持锁定并可从订单中心继续处理。
12. 顶部应显示当前账号；开启无障碍模式并刷新或重新登录后，开关、后排偏好和无障碍座位需求应自动恢复。
