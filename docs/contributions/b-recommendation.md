## 与 A 合并入口

- B 返回标准座位 ID 数组，例如 `["F-10", "F-11"]`；编号规则为 `排号-座位号`。
- A 将结果同时传给 `highlightedSeatIds` 和 `selectedSeatIds`，用户可以直接确认或清空后手动改选。
- 人数、票种、偏好或场次变化时，由 `app.js` 触发推荐刷新；B 无需操作 Canvas。
- 合并时优先替换 `findBestSeatGroup()` 的占位评分逻辑，不修改 C 的 `seatState`、订单状态或座位 ID 结构。
