# 管理员场次运营台

管理员使用 `admin / admin123` 登录后，页面从普通购票流程切换为场次运营视图；普通用户和游客页面不受影响。

## 页面结构

- 顶部：“全部场次”按钮，打开跨场次比较弹窗。
- 左侧：当前场次选择、影片、日期时间、影厅、票价和运营指标。
- 中间：当前场次座位状态图，展示可用、锁定和已售座位；管理员模式只读，不会产生临时选座。
- 右侧：只显示当前场次订单，支持状态筛选。管理员可以取消待支付预订、办理已支付订单退票，但不能替用户支付。

切换左侧场次时，座位图、库存、运营指标和右侧订单同步刷新。比较弹窗中的“查看”按钮可以关闭弹窗并切换到对应场次。

## 指标口径

| 指标 | 计算方式 | 说明 |
| --- | --- | --- |
| 已售 | `seatState.status === "sold"` 的数量 | 来自当前座位状态 |
| 锁定 | `seatState.status === "reserved"` 的数量 | 包含待支付锁票 |
| 可用 | `seatState.status === "available"` 的数量 | 可继续销售的座位 |
| 上座率 | `已售 / 影厅容量 × 100%` | 保留一位小数 |
| 场次订单 | `store.getOrders({ scheduleId })` 的数量 | 包含全部订单状态 |
| 估算票房 | `已售座位 × 场次单价` | 课程项目演示值，不是真实财务收入 |
| 观众满意度 | 有效 `viewerRating.ratingValue` 的算术平均值 | 只接受 1–5 分；不混入系统体验评分 |

Mock 数据中的部分已售座位没有一一对应的订单记录，因此不能用订单金额直接还原全部历史票房。界面统一使用“估算票房”表述，避免误解。

“全部场次”中的总体满意度按所有场次的有效观众评分加权汇总，不对各场次平均值再次取平均。没有有效观众评分时显示“暂无”。

## 权限边界

- 普通用户只能看到自己的订单，并可继续支付、取消或申请退票。
- 管理员按当前场次查看所有用户订单及用户 ID。
- 管理员不能进入观影需求表单、不能选择座位、不能替用户完成支付。
- 管理员取消或退票后，订单状态和座位库存同步刷新。
