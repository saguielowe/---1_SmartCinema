## 验收结果

| 项目 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| 角色切换 | 登录管理员账号 | 隐藏购票进度、观影需求和 AI 顾问，显示运营台 | 通过 |
| 默认场次 | 首次进入管理员视图 | 自动选择首个场次并加载座位与订单 | 通过 |
| 场次联动 | 切换左侧“当前场次” | 场次信息、指标、座位图和订单同步更新 | 通过 |
| 只读座位图 | 在管理员视图操作 Canvas | 不可聚焦、点击或占用座位 | 通过 |
| 场次订单 | 查看右侧订单中心 | 只显示当前场次订单及用户 ID | 通过 |
| 管理操作 | 查看待支付和已支付订单 | 可取消预订或办理退票，不显示“继续支付” | 通过 |
| 运营指标 | 查看左侧指标 | 展示上座率、可用/锁定座位、订单数和估算票房 | 通过 |
| 全部场次比较 | 点击顶部“全部场次” | 大尺寸弹窗展示 12 个场次及汇总指标 | 通过 |
| 弹窗切换 | 点击比较表中的“查看” | 关闭弹窗并切换到对应场次 | 通过 |
| 普通用户回归 | 登录普通用户账号 | 恢复原购票流程与个人订单视图 | 通过 |
| 响应式样式 | 检查桌面与窄屏 | 圆角场次选择框正常；桌面弹窗无需横向滚动 | 通过 |
