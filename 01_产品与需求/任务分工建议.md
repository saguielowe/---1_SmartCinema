## 当前推荐分工

### A：座位渲染与选座交互

- 负责 Canvas 影厅绘制
- 负责座位数据渲染
- 负责手动选座、多选、推荐高亮
- 负责输出当前已选座位

对应文件：

- `03_源码/js/seat-map.js`

### B：智能推荐与评分逻辑

- 负责推荐规则
- 负责连续座位搜索
- 负责情侣 / 家庭 / 团体 / 老年 / 儿童规则
- 负责推荐理由与观影评分

对应文件：

- `03_源码/js/recommendation.js`

### C：订单中心与数据状态

- 负责登录注册
- 负责用户 / 管理员权限
- 负责订单中心和假支付流程
- 负责 LocalStorage、座位状态和热度数据

对应文件：

- `03_源码/js/store.js`

### D：页面整合与体验收口

- 负责注册页和选座页整体 UI
- 负责响应式与无障碍模式
- 负责模块接线、联调、测试和文档收口

对应文件：

- `03_源码/index.html`
- `03_源码/css/style.css`
- `03_源码/js/app.js`

## 一句话理解

- A 做“选座组件”
- B 做“推荐脑子”
- C 做“状态和订单”
- D 做“页面外壳和最终整合”

- 推荐输入输出字段
- 订单与锁票字段
- 用户与管理员的页面权限差异
