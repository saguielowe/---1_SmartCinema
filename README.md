# SmartCinema

## 本地预览

双击项目根目录的 `启动预览.cmd`，脚本会自动启动静态网页服务与 WebSocket 实时选座服务，并且只打开一个预览页面。没有正式登录会话时，页面会自动使用 `guest` 游客账户，便于直接验收完整购票流程。

也可以手动开启两个终端。第一个终端在项目根目录运行：

```powershell
python scripts/realtime-server.py
```

第二个终端进入 `03_源码` 目录运行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8080/index.html`。

清华大学《Web前端技术实训》大作业 1：智能影院选座系统。

当前版本已集成 A/B/C 的 Canvas 选座、智能推荐和订单存储能力；D 已补齐正式账号入口、订单分页筛选、响应式布局和完整无障碍设置，并新增问答式观影顾问、连续拖拽选座动画、WebSocket 多人选座模拟与三套个性化主题，可以跑通“描述需求—确认座位—模拟支付—查看取票码”主流程。

演示账号：

- 普通用户：`testuser / 123456`
- 管理员：`admin / admin123`
- 不登录时自动使用 `guest` 游客账户
