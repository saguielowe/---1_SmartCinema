# SmartCinema

清华大学《Web前端技术实训》大作业 1：智能影院选座系统。

这个仓库现在的目标不是直接堆代码，而是先把小组协作最容易卡住的部分固定下来：分工、公共字段、功能边界、Git 约定。

## 当前重点

1. 确认 4 人分工认领
2. 统一公共数据结构
3. 明确核心功能优先级
4. 在统一接口上并行开发

## 目录说明

- `00_题目材料`：原始作业说明与老师要求
- `01_产品与需求`：早期需求整理
- `02_设计稿与素材`：视觉稿、图标、配色、导出素材
- `03_源码`：前端源码主目录
- `04_测试与验收`：测试记录、问题清单、验收截图
- `05_提交材料`：报告、清单、最终提交物
- `99_归档`：历史草稿与废弃方案
- `docs`：小组协作与开发规范

## 开发建议

最稳的推进顺序：

1. 登录注册与电影/场次信息
2. 影厅数据结构与 Canvas 座位图
3. 智能推荐与手动选座
4. 订单中心与本地存储
5. 热度地图、评分、无障碍模式
6. 说明文档、AI 使用记录、最终验收

## 运行方式

当前推荐目标是最终保留一个可直接打开的入口页：

- `03_源码/index.html`

如果开发阶段使用更细的文件拆分或工具链，最终也要整理成便于助教直接评分的静态版本。
