# SmartCinema

## 本地预览

双击项目根目录的 `启动预览.cmd`，脚本会自动启动本地服务器并打开网页。没有正式登录会话时，页面会自动使用 `guest` 游客账户，便于直接验收完整购票流程。

也可以在 `03_源码` 目录手动运行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8080/index.html`。
